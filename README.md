# temp-blanket

Starting a new pipeline project to show/grow data engineering skills in my job search.

Want to be able to use an API to pull a year's worth of temp data (high temp), store it, then allow a user to assign colors to bands of temperatures. This is how knit/crochet temperature blanket projects work.
